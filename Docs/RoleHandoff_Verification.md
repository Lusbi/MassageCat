# 角色彈跳與交接

## 已實作規格

- Hit 在約 0.35 秒內壓縮、回彈、回到原位；連打從當前姿態接續，變形幅度不累加。
- 療癒值立即套用；達到完成條件時立即停止接受戰鬥按鍵。
- 完成後停留 0.4 秒，再向右移動、上下起伏並淡出 1.2 秒。
- 舊角色移動到一半時，新角色從右側以 1 秒移動、起伏及淡入至原位。
- 舊角色完全離場且新角色到定位後恢復輸入，交接期間按鍵不補算。
- 拼字倒數、答題、延遲換題與現有回饋動畫暫停，交接後接續。
- 番茄鐘沿用原本計時，不因角色交接暫停。
- 交接期間阻擋箭頭與圖鑑選角，以及拼字模式按鈕；設定選單仍可使用。
- 退場圖像於初始化建立一次並重複使用；每幀僅更新位置、縮放與顏色。

## 使用者手動驗證

本次僅完成檔案修改與靜態檢查，尚未執行 Unity、編譯、測試或畫面驗證。

1. 一般模式按一下及快速連按：角色應柔軟回彈，停止後回到原位，不越變越大。
2. 療癒至 100%：先短暫停留再緩慢離場，途中可看見新舊兩個角色；約兩秒後新角色定位。
3. 交接時持續按鍵：療癒值與番茄累積按鍵不增加，定位後也不補算；箭頭與圖鑑不能更換角色，設定可開關。
4. 拼字觸發交接：倒數暫停，按鍵不判定錯誤；定位後延續挑戰。若觸發交接的單字已答完，恢復完成演出後正常出下一題。
5. 番茄鐘運作及結算時檢查計時與交接，確認沒有因交接重啟計時或重複結算。
6. 離開遊戲主面板再返回：不得殘留退場副本或永久鎖住輸入。

交接開始、中點與恢復時會輸出 `[Codex驗證]` 暫時 log，僅限 Editor / Development Build。
