# Database
ClientDatabase module is designed to handle the client db in Unity. It can help developers to create the database quickly.

## Namespace
JSLCore.Database

## Public Methods - ClientDatabaseManager
| Name                   | Parameters                                                            | Description                                                                  |
|------------------------|-----------------------------------------------------------------------|------------------------------------------------------------------------------|
| Initialize()           |                                                                       | Initialize the Database module, it would load datas with AssetBundles. |
| GetData<T>(string key) | T : The data type you want to load key: The data key you want to load | Load the data type you want to load with data key.                           |
| GetDatas<T>()          | T: The data type you want to load                                     | Load all datas of the data type T.                                           |
